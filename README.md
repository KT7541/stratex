# Stratex website

Static GitHub Pages-ready site.

## Deploy
1. Upload the contents of this folder to a GitHub repository.
2. In Settings > Pages, choose Deploy from a branch.
3. Select `main` and `/(root)`.
4. Replace `https://YOUR_GITHUB_USERNAME.github.io/stratex/` in `index.html` with the live URL.

Founder image files are stored locally in `assets/` so the site does not depend on LinkedIn image hotlinking.
